#Speedtest Web GUI

Speedtest Web GUI is an add-on package for IPFire that allows you to run speedtest-cli either directly from the IPFire Web GUI or behind the scenes at regularly scheduled intervals with results written to a log file in JSON or CSV format.

speedtest-webgui-0.8.3-1.ipfire is for IPFire Core205 and earlier.
speedtest-webgui-0.8.4-2.ipfire is for IPFIRE Core206 and later.
